# Foundry IQ

Foundry IQ gives your agents a shared knowledge layer, so they can find and use trusted enterprise content with the right permissions. Here's what's new at Microsoft Ignite 2026, plus a deck, a demo video, sessions, and resources to get started.

## What's new at Ignite 2026

- **Knowledge graphs in Foundry IQ (public preview):** Entities, topics, and relationships that improve retrieval quality, measured with evaluations.
- **Microsoft-Retriever-1 (public preview):** Faster agentic retrieval, with quality, latency, and cost gains measured through evaluations.
- **Agent grounding and control:** The Foundry IQ plugin.
- **Enterprise readiness (generally available):** SharePoint knowledge sources, including security features.
- **Serverless (generally available):** Serverless for Foundry projects, available in more regions.
